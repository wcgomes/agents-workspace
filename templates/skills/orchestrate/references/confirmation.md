# Confirmation presentation

Use when a Phase 4.5 trigger applies. Name the trigger, then present:

```
Trigger: [destructive | ambiguous scope | irreversible/outward-facing | unusually costly | user asked]

Team roster:
- [Role] → [Selected agent] : [Scope]
- ...

Execution plan:
- Parallel: [scopes with no dependencies]
- Sequential: [dependency chain]
- Review points: [strategic points chosen]

Complexity: [single/multi-domain/cross-functional, coordination pattern]
```

Wait for the user's answer before any handoff. The user may adjust team, scope, order, or review points. A changed plan needs fresh approval only if a trigger still applies to the change.
