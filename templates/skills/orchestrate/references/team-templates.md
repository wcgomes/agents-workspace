# Team templates and coordination patterns

Starting points only. Adapt team size to the request: one specialist to ten or more.

## Coordination patterns

| Pattern | Use / flow |
|---|---|
| Full Parallel Discovery | Independent perspectives on one topic → synthesize. |
| Parallel Kickoff → Merge → Review | Independent work feeds an integrator → review. |
| Sequential with Quality Gates | Output dependencies; gate-check each handoff. |
| Single Agent Structured | One-domain task → one exact or adjacent specialist. |

## Templates

Agent names below are **illustrative only**. Match equivalent roles from the session-listed pool and dispatch only listed identifiers. Review and testing roles run at strategic points (SKILL.md Phase 6), not per task.

| Template | Phase: role (illustrative match) | Pattern |
|---|---|---|
| Software development | Planning: UX/design (UX Researcher, UI Designer); architecture (Software Architect). Execution: frontend (Frontend Developer); backend (Backend Architect, Senior Developer). Verification: review (Code Reviewer); testing (Reality Checker, API Tester). | Parallel Kickoff → Merge → Review |
| Bug fix / incident | Investigation: debug (Incident Response Commander). Fix: domain developer. Verification: review (Code Reviewer); testing (Reality Checker). | Sequential with Quality Gates |
| Marketing campaign | Strategy: planning (Growth Hacker, Product Manager). Execution: content (Content Creator). Verification: analytics (Analytics Reporter). | Parallel Kickoff → Merge → Review |
| Product discovery | Parallel: market (Trend Researcher); technical (Software Architect); brand (Brand Guardian); growth (Growth Hacker); UX (UX Researcher); support (Support Responder). Synthesis: coordination (Project Shepherd). | Full Parallel Discovery |
| Content / documentation | Planning: strategy (Content Creator). Execution: writing (Technical Writer). Verification: review (Reality Checker). | Sequential with Quality Gates |
| Wiki setup / creation | Discovery: workspace research (Software Architect). Execution: technical writing (Technical Writer). Verification: consistency review (Reality Checker). | Sequential with Quality Gates |

Wiki setup: broad or persistent docs need the consistency review. Without a wiki-specific specialist, keep research and writing as separate fallback handoffs.
